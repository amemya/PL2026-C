# 解答・解説

## 問1. 関数定義

### 1) 自然数x,yの剰余`x%y`を反復によって計算する関数`mod()`
**解説:**
剰余 `x % y` は、`x` から `y` を引けるだけ引いた残りの値です。反復（ループ）を用いる場合は、`x` が `y` 以上である間、`x` から `y` を引き続けることで計算できます。

```c
int mod(int x, int y) {
    while (x >= y) {
        x -= y;
    }
    return x;
}
```

### 2) 自然数x,yの割り算`x/y`を再帰によって計算する関数`div()`
**解説:**
割り算 `x / y` の商は、`x` から `y` を何回引けるかを表します。再帰を用いる場合、引かれる数 `x` が割る数 `y` より小さくなったら `0` を返し、そうでない場合は `1 + div(x - y, y)` として1回分カウントを増やしつつ再帰呼び出しを行います。

```c
int div(int x, int y) {
    if (x < y) {
        return 0;
    }
    return 1 + div(x - y, y);
}
```

### 3) 要素数nの配列`x[]`に対して全要素の合計値を計算する`total()`
**解説:**
配列の合計値は、結果を保持する変数（初期値は0）を用意し、ループを用いて配列の各要素を順番に足し合わせることで計算します。

```c
int total(int n, int x[]) {
    int sum = 0;
    for (int i = 0; i < n; i++) {
        sum += x[i];
    }
    return sum;
}
```

**別解（再帰を用いた場合）:**
要素数が0になれば合計は0とし、それ以外の場合は「最後の1要素＋残りn-1個の合計」として再帰的に足し合わせることで計算することも可能です。

```c
int total(int n, int x[]) {
    if (n == 0) {
        return 0;
    }
    return x[n - 1] + total(n - 1, x);
}
```

## 問2. ファイル，文字列処理

**解説:**
※プログラムの全体コードは[別ファイル](create_file.c)に作成済みのため、ここでは空欄の解説のみ記載します。

*   **[空欄a] `string.h`** : 文字列の長さを取得する `strlen` 関数を使用するために、このヘッダファイルをインクルードします。
*   **[空欄b] `%s`** : `scanf` で文字列を読み込むためのフォーマット指定子は `%s` です。
*   **[空欄c] `FILE`** : ファイルを扱うためのファイルポインタの型は `FILE *` （宣言では `FILE *fp;` となるため `FILE`）です。
*   **[空欄d] `LEN`** : 定義済みのマクロ定数 `LEN` を使用して、配列 `buf` のサイズを指定します（ここでは `64` になります）。
*   **[空欄e] `EOF`** : `scanf` は、入力が中断されたりストリームの終端に達したりすると、定数 `EOF` (End Of File) を返します。これを用いてループからの脱出判定を行います。
*   **[空欄f] `strlen`** : 文字列の長さを取得する `strlen` 関数を使用します。入力が1文字だけ（`strlen(buf) == 1`）の場合に終了する処理となっています。
*   **[空欄g] `fopen`** : ファイルを開く関数は `fopen` です。ここでは新規作成のために書き込みモード `"w"` で開いています。
*   **[空欄h] `NULL`** : `fopen` がファイルの作成・オープンに失敗した場合、戻り値として `NULL` が返されます。
*   **[空欄i] `%s`** : `printf` で文字列 `buf` （作成成功したファイル名）を表示するためのフォーマット指定子は `%s` です。
*   **[空欄j] `fclose`** : 使用が終わったファイルポインタは、必ず `fclose` を用いて閉じます。

## 問3. 関数呼出

**解説:**
プログラムの実行結果（標準出力）は以下のようになります。

```text
func1()
1
1
1
0
0
func2()
1
3
6
10
15
func3()
1
1
1
0
1
```

*   **`func1()` の解説:**
    引数の文字 `c` が `'a'` より小さい（大文字や数字など）、または `'z'` より大きい場合に `1` を返し、小文字の `'a'`〜`'z'` なら `0` を返します。
    文字列 `"QC6ct"` の各文字に対して呼び出されるため、`'Q'`, `'C'`, `'6'` は `1` となり、`'c'`, `'t'` は小文字なので `0` となります。
*   **`func2()` の解説:**
    文字列で表現された数字の各桁の値を数値として足し合わせていき、その都度合計を表示します。
    `"12345"` が渡されるため、`1`、`1+2=3`、`3+3=6`、`6+4=10`、`10+5=15` が順番に出力されます。
*   **`func3()` の解説:**
    引数 `x` を 2 で割った余り（一番下のビット）を表示し、`x / 2` で再帰呼び出しを行います。つまり、引数の 2 進数表現を下位ビットから順番に出力します。
    `23` は 2 進数で `10111` です。したがって、下位から順に `1`、`1`、`1`、`0`、`1` と出力されます。

## 問4. プログラミング

**解説:**
要求仕様を満たすカードゲーム（ババ無しのババ抜き）のシミュレーションプログラムのコードは[別ファイル](bbn.c)に作成しています。実装のポイントは以下の通りです。

*   **度数配列の活用:** 
    `f[d]` は現在の手札にある数字 `d` の枚数（ペアになると消えるため 0 か 1 になります）、`s[d]` はこれまでに配付された数字 `d` の総数（最大 4）を管理します。
*   **乱数と配布制限:**
    `rand() % 13 + 1` で 1〜13 を生成し、`s[d] < 4` を満たすまで再生成を繰り返します（これが仕様書にある「永久に終了しない可能性がある」原因となる無限ループの箇所です）。
*   **ペア成立と終了判定:**
    カードを引くたびに `s[d]` を増やし、`f[d]` を反転させます（1枚目なら手札の総数が増え、2枚目ならペア成立で除去され手札の総数が減ります）。ペア成立後に手札の総枚数が 0 枚になった時点でループを終了します。
