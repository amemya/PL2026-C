次の要求仕様・注意事項・実行例に従うような

old-maid-less Old Maid)のシミュレーションプログラム

**要求仕様:**
- 現在の手札を表示.
- 番号(1〜13)をランダムに生成し,手札として配付.
- ただし,生成済みの同番号が4枚以上となる場合,それを配付せず,別の番号を生成しなおす.
- ペア(同番号の2枚)が成立したら,それらを除去.
- 手札がゼロ枚になるまで,以上を反復.

**注意事項:**
- 通常のババ抜きとは異なり,ババ(ジョーカー)は不使用.
- 同番号の判定のため,度数配列f[]とs[]を有効活用.
- 配列要素f[d]は現在の手札の番号dの枚数.
  - 例:f[5] == 1 → 現在の手札として5番が1枚ある.
- 配列要素s[d]は配付済みの番号dの枚数.
  - 例:s[3] == 2 → すでに3番は2枚が配付された.
- 簡単のため,f[0]とs[0]は不使用.

**バグ(ではなく仕様):**
- 実際の乱数列によっては,永久に終了しない可能性がある.(しかし,気にしない.)
